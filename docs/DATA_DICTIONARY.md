## 1. Raw Industrial Telemetry Schema

The table below documents all fields ingested from raw telemetry logs (`data/synthetic/industrial_safety_telemetry.csv` and live input streams):

| Column Name | Data Type | Physical Unit | Valid Range | Nullable | Description & Domain Significance |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `record_id` | String | Identifier | Unique string | No | Unique tracking identifier for the shift observation (e.g. `REC_REF_PUMP_01_20240101`). |
| `timestamp` | Datetime | Date (YYYY-MM-DD) | 2024-01-01 to Present | No | Calendar date of the recorded operating shift. |
| `facility` | String (Categorical) | Facility Name | 5 Facilities | No | Operating industrial plant (e.g. Refinery-North, PetroChem-Alpha, HeavyFab-Plant3). |
| `unit_id` | String | Asset ID | Unique string | No | Physical asset identifier (e.g. `Refinery-North_CENTRIFUGAL_PUMP_01`). |
| `equipment_type` | String (Categorical) | Machine Class | 6 Classes | No | Functional asset category: Centrifugal Pump, Gas Compressor, CNC Machining Cell, Overhead Crane, Heat Exchanger, Conveyor Line. |
| `shift_type` | String (Categorical) | Operational Shift | `Day`, `Swing`, `Night` | No | Work shift during which telemetry was recorded. Night shifts induce circadian fatigue. |
| `ambient_temperature_c` | Float | Degrees Celsius (°C) | -50.0 to 80.0 | No | Outdoor / facility ambient temperature. Captures seasonal heat waves and winter freezes. |
| `process_temperature_c` | Float | Degrees Celsius (°C) | -20.0 to 250.0 | No | Internal operating fluid / metal temperature. Thermal excursions indicate cooling breakdown or friction. |
| `vibration_rms_mms` | Float | mm/s | 0.0 to 50.0 | No | Overall vibration velocity RMS (10 Hz - 1000 Hz) per ISO 10816 standards. Primary mechanical wear indicator. |
| `vibration_kurtosis` | Float | Dimensionless | 1.0 to 30.0 | No | Fourth statistical moment of vibration waveform. Values > 3.0 indicate impulsive shock events (bearing spalls/cracks). |
| `operating_pressure_bar` | Float | Bar (gauge) | 0.0 to 200.0 | No | Internal system hydraulic or pneumatic pressure. Excursions elevate rupture and seal breach risk. |
| `rotational_speed_rpm` | Float | RPM | 0.0 to 15,000.0 | No | Operating rotational speed. Static assets (Heat Exchangers) register 0 RPM. |
| `duty_cycle_pct` | Float | Percentage (%) | 0.0 to 100.0 | No | Percentage of shift time that the machine operated under active load. |
| `acoustic_emission_db` | Float | Decibels (dB) | 20.0 to 140.0 | No | High-frequency stress wave sound level. Spikes indicate cavitation, micro-fracturing, or poor lubrication. |
| `days_since_last_pm` | Integer | Days | >= 0 | No | Number of calendar days elapsed since the most recent preventive maintenance overhaul. |
| `pm_overdue_days` | Integer | Days | >= 0 | No | Days past the scheduled preventive maintenance interval. Direct measure of maintenance backlog. |
| `open_maintenance_tickets` | Integer | Count | 0 to 50 | No | Unresolved maintenance defect tickets logged in CMMS for this asset. |
| `daily_near_miss_count` | Integer | Count | 0 to 20 | No | Number of near-miss hazard reports logged on this asset during the current shift. |
| `near_miss_category` | String (Categorical) | Hazard Class | 7 Categories | No | Most critical hazard logged: Mechanical_Guard_Trip, Pressure_Excursion, Thermal_Spike, Slip_Trip_Fall, Chemical_Vapor_Weep, None. |
| `shift_overtime_hours` | Float | Hours | 0.0 to 24.0 | No | Overtime hours worked by operating crew. Correlates with cognitive fatigue and procedural shortcuts. |
| `operator_fatigue_index` | Float | Score (0 - 100) | 0.0 to 100.0 | No | Composite human fatigue index derived from shift timing, consecutive days on duty, and overtime. |
| `safety_audit_score` | Float | Score (0 - 100) | 0.0 to 100.0 | No | Score achieved on latest regulatory / internal safety compliance walk-through. |
| `incident_today` | Integer (Binary) | Flag (0 or 1) | 0, 1 | No | Whether an actual incident (equipment breakdown or occupational injury) occurred on this day. |
| `incident_next_7d` | Integer (Binary) | Target Flag (0 or 1)| 0, 1 | No | **Primary Prediction Target**: 1 if an incident occurs in days [t+1, t+7]; 0 otherwise. |
| `days_to_incident` | Integer | Days | 1 to 30 | No | **Time-to-Event Survival Target**: Exact days until first incident in lookahead window, or 30 (censored). |
| `survival_event` | Integer (Binary) | Event Flag (0 or 1)| 0, 1 | No | Event indicator for survival analysis (1 if uncensored incident observed, 0 if censored). |
| `data_origin` | String | Provenance Label | String | No | Dataset provenance label: `"domain_grounded_synthetic_benchmark"`. |

## 2. Engineered Features Schema

The table below documents primary features generated by `SafetyFeaturePipeline`:

| Engineered Feature | Base Signal | Derivation / Formula | Domain Rationale |
| :--- | :--- | :--- | :--- |
| `sin_day_of_year`, `cos_day_of_year` | `timestamp` | $\sin(2\pi \cdot \text{doy} / 365.25)$ | Captures periodic annual seasonality in temperature and plant turnarounds. |
| `vibration_rms_mms_roll_mean_7d` | `vibration_rms_mms` | 7-day rolling mean per `unit_id` | Smooths transient sensor blips; captures sustained mechanical degradation. |
| `vibration_rms_mms_roll_std_7d` | `vibration_rms_mms` | 7-day rolling standard deviation | Measures mechanical stability; increasing volatility signals impending mechanical failure. |
| `near_miss_sum_7d`, `_14d`, `_30d` | `daily_near_miss_count` | 7, 14, 30-day rolling sums | Quantifies warning frequency accumulation (Heinrich's leading indicator). |
| `near_miss_ewm_4d` | `daily_near_miss_count` | Exponential weighted mean ($\tau = 4\text{d}$) | Emphasizes recent bursts of hazard reports over distant historical events. |
| `near_miss_acceleration_ratio` | `near_miss_sum_7d` | $(\text{rate}_{7d} / \text{rate}_{30d})$ | Identifies accelerating hazard escalation. Ratio > 1.0 means hazards are multiplying. |
| `is_vibration_alert` | `vibration_rms_mms` | $\mathbb{I}(\text{RMS} \ge 2.8\text{ mm/s})$ | Binary indicator of ISO 10816 Zone C alert status. |
| `is_vibration_danger` | `vibration_rms_mms` | $\mathbb{I}(\text{RMS} \ge 4.5\text{ mm/s})$ | Binary indicator of ISO 10816 Zone D danger status. |
| `thermal_gradient` | Temperature | $T_{\text{process}} - T_{\text{ambient}}$ | Identifies abnormal machine heat retention independent of weather swings. |
| `maintenance_backlog_index` | PM & Tickets | $(\text{overdue} + 1) \times (\text{tickets} + 1)$ | Multiplicative compounding risk of neglected maintenance work. |
| `human_mechanical_stress` | Fatigue & Vibration | $\text{fatigue}_{\text{norm}} \times \text{vibration}_{\text{RMS}}$ | Interaction term: fatigued operators managing erratic, vibrating equipment. |
| `swiss_cheese_barrier_breaches` | Multiple signals | Sum of active barrier failures | Quantifies simultaneous holes in safety barriers per Reason's model. |
